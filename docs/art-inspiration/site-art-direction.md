# PC 美术设计稿：光的航迹

当前在 `dev-art` 开发，接续相册默认浏览的 `6c3f035`。作者对 `034ffc8` 的评价是：
只认可首页首屏与画窗展开的方向，其余页面仍粗糙，丢失了色彩层级和编排。
本稿先完成 **PC 视觉设计**，交给作者评价；PC 满意后再处理其他媒体端。
滚轮、快速拖动只是作者举例，交互收尾与性能不能抢在视觉设计之前。

## 这套画面的关系

首屏的柔光建筑与画窗保留。越过画面后，读者进入青色纸面的文字区，再来到紫色收藏室，
最后落在暖色的作者便笺。颜色承担章节职责，字号与图像尺度承担注意力主次，
不用每一段都重复一张大标题配一幅大图。

### 首页：从画窗到书写，再到收藏与作者

- **章目：** 首屏之后用同一行标出写作、收藏与作者，数量来自站内实际内容。
  三个入口分别使用青、玫瑰、暖金，后续章节保持对应关系。
- **文章：** 主文以大封面与文字纸面组成跨栏版面；标题的主题、展开说明和摘要分级。
  两篇后续文章并排，尺度退到主文之后，目录入口收在章末。年度、日期、分类有各自位置，
  避免所有信息挤成同一层文字，也避免靠巨大的空白拉长章节。
- **回廊：** 与相册共用完整收藏来源，当前是 173 项，保留稳定作品 ID 和原顺序，
  不再硬编码五张互不关联的精选。数量、当前作品和进入完整画廊的关系都在画面中说明。
  正中作品更高、更清楚，两侧逐渐退远，横竖比例保留；首屏建筑底图以暗部环境延续到这里。
  这是首页回廊的设计稿，不等于已完成相册独立展览模式或交互验收。
- **作者：** 暖色纸面、人物画片和个人表达收尾。人物图有边缘、落影和题注，正文按身份、
  研究兴趣与轻松表达组织。保留作者原有“一个相信童话的妄想家”语气，不新增履历。
- **小控件：** 桌面音乐默认收成小按钮，悬停或聚焦时展开曲目信息，给正文和章节底部让位。

### 页面之间：同一套字阶，各自的构图

| 页面 | PC 构图与阅读目的 |
| --- | --- |
| 文章发现 | 青色页头以真实近期封面形成书页组；年份作为时间线的侧边索引，封面、标题、摘要依次分级 |
| 知识目录 | 青色索引纸与白色结果纸区分导航和阅读，搜索单独占据清晰的一行；保持检索页的安静与密度 |
| 阅读页 | 标题信息与封面并置，压缩进入正文前的长度；正文、目录与旁注仍沿用既有阅读网格 |
| About | 暖色身份介绍 → 青色研究三联页 → 深色兴趣段 → 暖色联系便笺；研究图形分别呼应双向语音、情感交流和音乐 |
| 相册 | 玫瑰色页头接原有收藏布局，与首页回廊共用内容语义；默认浏览和媒体查看器保留 |
| 友链 | 标题与便笺形成前后层，真实站点作为白色纸面条目；不为一个站点编造更多内容填版 |

PC 字阶集中在 `global.css`：主要页面标题约 64–84px，章节标题约 40–54px，
长文章标题约 36–48px，文章条目再降一级。首页首屏承担展示任务，保留更大的中文构图；
英文网名按实际字宽单独处理，不机械套用中文标题字号。

`ResearchSketch.astro` 是装饰性的原创矢量图形，不是测量波形、生理数据或研究结果。
公开文字继续依照 `voice.md`、i-have-adhd 和 humanizer 检查阅读顺序、断行与语气。

## 实现与素材

艺术组件集中在 `src/components/art/`，页面自身保留结构与内容；共享字号、纸色在全局样式。

| 文件 | 职责 |
| --- | --- |
| `VoyageHero.astro`、`voyage-hero.ts` | 已认可的画窗方向与首屏构图 |
| `HomeExperience.astro`、`art/home.css` | 首页文章、章目和作者的编排 |
| `LightTable.astro`、`light-table.ts` | 与完整收藏连接的回廊画面、邻近作品呈现与作品入口 |
| `ResearchSketch.astro` | About 三项研究兴趣的矢量图形 |
| `art-motion.ts` | 已开始的局部运动状态；完整手势与滚轮回归留到视觉确认后 |
| `ApertureOpening.astro`、`OrbitSculpture.astro` | 既有开场与 404 图形，本稿未重新扩展 |

环境图 `src/assets/art/voyage-atrium.webp` 于 2026-10-30 使用 OpenAI 图像生成工具制作，
原图 1672×941，WebP 约 141 KB；它是固定视点的柔光建筑与水面，不是实时 3D、反射或光照。
角色、封面和收藏来自站内现有素材，没有把参考站截图用于网站资产。
参考作品带来的判断仍是 Unseen 的空间与进入感、Immersive Garden 的负空间与主体尺度、
Lusion 的章节关系及 Samsy 的暗部光色，不声称复现它们的技术或达到同等完成度。

## 当前阶段与证据

本稿只检查 PC，在 Chrome 的 1440×900 CSS 视口逐页实看：首页文章、收藏、作者，
About 身份、研究、兴趣与联系，文章发现、目录、阅读页和相册。截图保存了首屏之后的
完整章节，不以首屏截图替代全站评价。基础类型与生产构建检查用于保证设计稿可运行，
不把检查通过写成视觉已获作者认可。

滚轮进度与回廊状态已有早期改动；完整快拖、触控、减弱动态、脚本回退与性能验收
尚未针对这份设计稿完成。其他媒体端适配按作者决定暂缓，不沿用旧版验证结论。
