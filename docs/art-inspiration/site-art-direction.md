# 全站美术：光的航迹

开发分支为作者指定的 `dev-art`，接续相册默认浏览的 `6c3f035`。
首轮 `b500249` 被作者指出缺少编排、完成度不足。当前实现重做了首页章节关系，
以下描述当前选择，不把候选风格或 Agent 判断写成作者的永久偏好。

## 构图与叙事

首页从一扇画窗开始。左侧中文标题与右侧角色形成主次，柔光建筑和水面提供环境，
原生滚动逐渐展开同一幅插画。标题退场后，原有引语落入完整画面；继续向下，
纸面文章接住画面，然后进入深色收藏，最后回到作者本人。

- **进入与展开：** 首屏、展开中段、完整插画各有独立构图。窗口大小、圆角、
  取景和明暗随章节进度变化，反向滚动恢复原状态。没有替换原生滚动手感。
  手机重新安排标题尺度、段落宽度与角色焦点，不直接裁切桌面版。
- **文字：** 一篇主文以大封面配真实标题和摘要，两篇后续文章压成线性条目。
  日期、分类、标题的字号各有职责；完整浏览和检索仍由文章页、知识目录承担。
- **收藏：** 五幅真实收藏按原比例展开，不再统一套白色纸框。相邻作品的真实宽度
  决定间距，透视和明暗只表达前后位置。拖动直接跟随输入，松手吸附；按钮、
  方向键和点击邻幅提供替代操作。它是首页精选，完整相册展览仍未实现。
- **作者与邻居：** 首页以人物和个人表达收尾。About 将身份、简介、当前状态与
  人物图放在同一组构图中；友链从引入直接接入真实条目，移除原先空转的雕塑首屏。
- **发现与阅读：** 文章页保留时间线，缩短手机引入段，增大日期、路径和标签。
  相册页头移除无内容关系的轨道装饰，保留作品和描述。目录、正文继续使用安静的
  纸色、细线与昼夜环境，不叠加首页长舞台。
- **局部细节：** 音乐控件和首屏向下提示错开，手机音乐控件留在左侧，避免挡住
  回廊切换按钮；页尾接入共享导航与 RSS。404 沿用首轮的夜景与明确返回入口。

参考关系：Unseen 的建筑负空间、进入感和直接操纵；Immersive Garden 的主体尺度
与展览式留白；Lusion 的章节变化；Samsy 的暗部与局部亮色。参考原站访问不稳定，
本轮复核过收录的官方画面，不能据此声称验证了它们当前的交互或具体算法。

## 实现与素材边界

艺术代码集中在 `src/components/art/`：

| 文件 | 职责 |
| --- | --- |
| `VoyageHero.astro`、`voyage-hero.ts` | 画窗静帧、昼夜取景、原生滚动进度与可见场景更新 |
| `ApertureOpening.astro` | 会话内一次开场；图片/字体就绪后收束，可跳过，有失效保护 |
| `LightTable.astro`、`light-table.ts` | 五幅精选、比例与间距、拖动/键盘/按钮、选择恢复、相册深链 |
| `OrbitSculpture.astro` | 404 使用的 SVG 雕塑；唯一 ID 避免渐变冲突 |
| `home.css` | 首页图文编排与章节衔接，选择器限于首页 |

移除了已无使用方的 `ArtDirection.astro`。没有新增动画库、客户端路由或实时后端。
开场和回廊仍是普通 DOM/CSS；画窗仅在可见且需要更新时请求帧，不保持空转循环。

`src/assets/art/voyage-atrium.webp` 是为本轮生成的环境底图：2026-10-30 使用
OpenAI 图像生成工具制作，原始画幅 1672×941，导出 WebP 约 141 KB。制作方向为
低饱和灰紫、矿物粉与象牙色的柔光建筑、浅水和远处地平线，左侧留给中文标题。
它是一张固定视点画面；水面、光线与反射不是实时计算。夜间使用独立色调处理，
角色插画继续使用本站已有的昼夜素材。没有把参考网站截图用于本站素材。

精选图片与 `getGalleryEntries()` 的原始 URL 匹配，共用稳定 ID。修改精选时更新
`LightTable.astro` 中五张导入与顺序；缺少对应收藏会使构建失败。脚本可用时打开
相册查看器，返回恢复会话中的选择；脚本关闭时以横向列表展示，链接直接打开原图。
产物校验同时检查原图与 `data-gallery-href` 中的作品 ID。

减弱动态或窗口高度不超过 600px 时，首页回到静态首屏；减弱动态时回廊取消过渡，保留操作。
脚本关闭时首页内容仍然存在，不留下需要脚本才能穿过的空白长舞台。
公开文案按 `voice.md`、i-have-adhd 和 humanizer 检查层级、断行和语气，未新增履历事实。

## 验证边界

本轮在生产构建和开发预览中复核首页、About、友链、文章发现、目录与相册。
Chrome 检查桌面 1440×900、手机 390×844 和最窄 320×800 的真实 CSS 视口；
IAB 补充日夜与默认窗口检查。IAB 的视口覆盖截图有绘制异常，最终截图使用 Chrome，
没有把截图异常当作网页内容的空白。

实际操作检查了画窗起点/中段/终点、主题切换、回廊按钮/方向键/鼠标拖动、点击打开
对应作品及返回恢复。脚本关闭使用仅本机的 CSP `script-src 'none'` 预览验证，测试
入口不进入仓库或发布产物。`pnpm verify` 覆盖类型、相册行为、构建与站内链接。

截图证明构图；不能证明帧率或输入延迟。未测试真机触摸、系统减弱动态设置和帧率
压力；减弱动态分支作代码核对。环境底图、CSS 透视均不能等同于参考作品的实时 3D。
