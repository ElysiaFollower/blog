# PC 美术设计稿：滚动中的编排

当前分支 `dev-art`。作者认为 `b33e5dd` 比前稿稍好，但文章章节方正、场景缺少进入感，
回廊的中心和侧面不够明显；About 方向配图不合适，文章页和画廊的页头缺少衔接。
本轮继续 PC 视觉设计，其他媒体端与系统性能工作仍在之后。以下是本稿实现，尚待作者评价。

## 关键状态与节奏

### 首页文章：按时间翻页

首页与文章页共同使用 `getVisiblePosts()`，按发布时间降序取最近三篇。开发环境两处
都显示草稿；生产环境两处都排除草稿。此前首页自己排除了草稿，导致开发预览的“最新”
不一致，并非发布时间排序函数本身有误。

文章章目接入固定阅读舞台。滚动推进三篇文章，封面和文字纸页从后侧靠近，上一页退到
左后方；每篇有稳定的停留区间。切换时使用实体纸面遮盖，先退去旧文字，再显露新文字，
避免两篇文字交叉淡化成重影。页码提供直接跳转，完整文章与目录入口始终明确。
最后一篇的提示接到回廊，青色文字区转入深紫收藏室。

### 首页回廊：先展开，再观看

回廊仍连接完整收藏来源，当前 173 项。进入可见区域时，邻近展片按错位、转角与深度
依次展开；稳定后中心作品放大，两侧明显倾斜并退远，减少原先均匀平铺的感觉。
中心缩放连续依赖位置，不等到索引改变才突然换大小。当前标题、编号与进入完整画廊的
关系保留。暖色作者段作为活动场景之后的停顿，本轮未给它叠加另一套演出。

### About：文字方向，画面让位

移除了 `ResearchSketch.astro` 及三联图形。研究方向保持为 `profileConfig.research`
中的文字纵列，左侧引入留在视野内，右侧各项随着浏览进入；增删方向无需制作主题图片。
身份画片离开时有轻微位移和尺度变化，接到安静的文字段。

兴趣段先呈现完整插画与标题。滚动后，画面向左收拢，右侧依次让出简介与兴趣列表的空间，
再接到联系入口。整幅画面和分幅阅读是同一场景的两个状态，向上滚动可以返回。
没有新增人物事实、研究成果或生理学图示。

### 文章发现：封面退去，时间线接住

移除页头叠放的三张封面，次级浏览导航收成简洁页签。标题、引入、细线和年份索引沿同一
排版轴线组织，底色连续过渡；滚动时标题收小、线条展开，接到原有时间线。时间线的
年份、封面、标题与摘要结构保留，不用长距离固定舞台阻挡按时间浏览。

### 画廊：从入口走向收藏

使用浏览区开头的三幅现有收藏组成入口，而不是另造一组与收藏无关的插图。两侧画面
向外打开，中央画面扩大，标题退场；继续滚动，瀑布流从同一幅画面的下方接入。
入场只负责进入感，完整收藏继续由原有浏览组件承担，比例、原图、动态媒体和查看器保留。

从作品深链 `#work=…` 进入时直接观看作品，跳过入场，以免切断既有看图上下文。

## 实现与素材

艺术代码集中在 `src/components/art/`：

| 文件 | 职责 |
| --- | --- |
| `VoyageHero.astro`、`voyage-hero.ts` | 已认可的首页画窗方向 |
| `WritingChapter.astro`、`writing-story.ts` | 最近文章的时间顺序、纸页关键状态与阅读停留 |
| `LightTable.astro`、`light-table.ts` | 收藏来源、展片展开、中心尺度与环绕透视 |
| `about-story.ts` | 身份、文字方向、兴趣画面与联系的衔接 |
| `GalleryPassage.astro` | 画廊入口、打开过程与深链跳过 |
| `journal-entry.ts` | 文章页的标题、底色与时间线衔接 |
| `scroll-scene.ts` | 将原生滚动映射到可反向的时间轴，不接管滚轮或滚动文档 |
| `art-motion.ts` | 场景进度平滑与既有回廊运动状态 |

没有新增动画库或后端。短窗口、减弱动态和窄屏不启用这套固定舞台，内容回到普通文档流；
本轮仍只对 PC 设计作视觉判断，未把该回退等同于其他媒体端已完成适配。

环境底图 `voyage-atrium.webp` 为前轮生成的固定视点建筑与水面；本轮复用它建立首页与
画廊的联系。角色、文章封面和入口作品来自现有内容，没有为 About 研究方向生成图片。
CSS 透视与预渲染底图不等同于实时三维场景、反射或布光。

## 验证与阶段边界

PC 在 Chrome 1440×900 CSS 视口实际检查文章的起点/切换中段/停留状态、回廊中心、
About 文字段与兴趣场景的展开前后、画廊入口到浏览区、文章页头到时间线。
静帧用于判断构图，滚动操作用于判断衔接；截图不能代替帧率和输入延迟测量。

`pnpm verify` 已通过（类型、现有画廊与动效测试、生产构建及站内链接检查）；最后标题排版调整后
重跑 `pnpm check`、`pnpm build`、`pnpm verify:build` 通过。保留原有 friends 配置未使用导入提示。
这些检查是运行底线，不代表视觉已获认可。真机触摸、完整性能、
其他媒体端及全部组合状态仍留在 PC 视觉方向确认后；不沿用旧版验证结果宣称新稿全部完成。
