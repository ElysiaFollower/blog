# 全站美术：光的航迹

2026-10-30，作者授权在相册默认浏览完成后进行全站美术优化；本轮在
`dev-art` 开发，基于相册最终提交 `6c3f035`。以下是本轮实现选择，
不是作者对所有候选风格的永久定论。

## 构图与节奏

保留角色插画、中文标题与昼夜环境，以轨道、柔光、纸张和深靛色建立连续性。
日间偏暖的纸色与灰紫，夜间偏靛的暗部与粉紫强调色，内容仍负责画面焦点。

- 首页：取消粗框与标题贴纸；插画、左下文字、右侧轨道形成前后关系。
  首次开场由环绕数字 17 的画面收束，接入首页；会话内只出现一次，支持跳过。
- 新近文章：一篇主文配两篇侧栏预览；减去容器边框与阴影，让封面和标题建立主次。
  内容索引以线性条目接续，之后进入深色精选回廊。
- 精选回廊：五幅真实收藏以有透视的纸质展片排列，允许直接拖动、有限惯性与吸附。
  横竖图完整呈现，横幅不被强迫填满竖向画框。按钮与方向键提供等价路径。
- About：人物与文字分层，研究与兴趣仍按原有内容展开；联系方式回到安静的纸面环境。
  身份、研究条目与联系方式数据未随美术更改。
- 友链：中文引入与轨道雕塑建立独立首屏；下方保留可扫描的线性条目。
- 文章发现、目录、正文与相册：延续纸色、细线和强调色，保留原有职责与内容密度。
  相册只调整环境与页头；浏览布局、加载、手势和媒体生命周期沿用前序重构。
- 404：沿用站内夜景，收拢轨道与文字，明确提供回首页、浏览文章两个出口。

参考关系：Unseen 启发开场衔接与直接操纵展品；Immersive Garden 启发展览式留白；
Samsy 启发暗部与局部亮色的关系。本站实现是 SVG、CSS 透视与事件驱动脚本，
没有复制参考站的素材，也不声称复现其三维场景、材质或算法。

## 实现与维护

艺术组件集中在 `src/components/art/`：

| 文件 | 职责 |
| --- | --- |
| `ApertureOpening.astro` | 首页开场；字体和当前主题图片就绪后收束，有超时与 CSS 失效保护 |
| `LightTable.astro`、`light-table.ts` | 五幅精选、比例展示、拖动/键盘/按钮、选择恢复与作品深链 |
| `OrbitSculpture.astro` | 可复用的 SVG 雕塑；传入唯一 `id`，避免渐变定义冲突 |
| `ArtDirection.astro` | 可见场景内的有限指针/滚动响应；无持续渲染循环 |
| `home.css` | 首页版式与章节衔接，选择器限于首页 |

精选作品来自现有本地素材，并与 `getGalleryEntries()` 返回的原始 URL 匹配，
因此与相册共用稳定 ID。修改精选时，更新 `LightTable.astro` 的五张导入及顺序；
作品若从相册删除，构建会明确失败。它是首页精选，不是全量相册的展览模式。

脚本可用时，点击当前展片进入相册查看器；返回后恢复会话中的选择。
脚本被禁用时，五幅作品变成原生横向列表，链接直接打开原图。产物校验同时检查
原图链接与 `data-gallery-href` 中的收藏 ID，不把动态深链当作不存在的 HTML 锚点。

减弱动态时跳过开场、取消场景视差与展片过渡，保留按钮和键盘操作。
未添加动画库、客户端路由或实时后端。跨页继续采用普通导航；试验过的原生
跨文档转场在快速返回时出现浏览器中断错误，已移除。

## 文案

沿用 `voice.md`，并按作者指定的 i-have-adhd、humanizer 检查阅读顺序与措辞。
功能入口直接说明动作；展示文字保留少量个人语气，不把每个段落都写成相同的
星光与旅途意象。没有为改版新增履历、研究成果或其他事实主张。

## 验证边界

生产构建在本机 IAB 浏览器检查 1440px、768px、390px、320px 视口。
已检查昼夜切换、精选按钮/方向键/鼠标拖拽、原图深链与返回、目录全文检索与
标签切换、文章交互图及 404。脚本回退通过仅本机的 CSP `script-src 'none'`
预览验证，不将测试入口加入仓库或发布产物。

`pnpm verify` 覆盖类型、相册行为、生产构建与站内链接。收藏 ID 校验另以不存在
的 ID 做负向检查，确认不会放过失效的精选链接。截图只证明构图，交互结论来自
实际操作；未测试真机触摸、其他浏览器、系统减弱动态设置或帧率压力，相关 CSS
与脚本分支仅作代码核对，不宣称稳定帧率或完整设备兼容性。
