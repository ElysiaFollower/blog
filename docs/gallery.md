# 相册维护

相册用于欣赏、浏览和分享收藏。作者在 2026-10-29 明确：审美体验优先；性能主要通过懒加载、分段展示、离屏资源管理改善，不自行以压缩画质或把动态内容改成静态图作交换。原图直接用于浏览是有效选择。

同一份收藏提供浏览与展览两种观看方式。默认仍为瀑布流浏览；开屏图片外的顶部切换条可选择“展览”，进入“光的回廊”。展览是环形悬浮陈列：完整画幅、透视纵深、柔光与渐隐倒影，昼间淡紫珠白、夜间深蓝玫瑰色。它是 CSS 3D 空间构图，并非自由行走的 WebGL 城市。具体美术效果仍由作者审阅。

作者在 2026-10-30 补充：图片必须完整展示，不裁剪，支持不同尺寸与比例；可在保持比例的前提下适度缩放，可有适度变化的图片间距，也可接受不过分的留白。不要为了填满版面牺牲作品。具体缩放与间距数值尚未被用户规定，属于需要结合屏幕与实际作品调整的排版选择。

布局是否采用，以实际画面、作品展示份量和浏览节奏为准。空白比例等数值只帮助定位问题，不充当审美评分或验收目标。

展览允许轻拖停在两幅作品之间，只有明确选择时才对齐。底部“自动漫游”可主动开启持续慢转，默认约 10 秒经过一幅；旁边的速度滑杆支持 0.25×–3×，播放中平滑变速并记住偏好。暂停保留当前位置，调整速度不主动开播。拖动、选择作品或打开查看器会关闭漫游，离屏和切后台则暂时挂起。首页收藏回廊也使用相同的连续运动核心，具体接口见 [连续运动](motion.md)。

## 代码边界

- `src/lib/gallery.ts`：构建期归一化来源，验证尺寸与唯一 ID；输出 `src/types/gallery.ts` 中可序列化的 `GalleryEntry`。
- `src/components/gallery/layout.ts`：无 DOM 的布局计算，保留比例。横幅与方幅通常占两个基础列，竖幅占一列；小尺寸素材保留单列，避免被放大成主图。窄屏在两列高度差较大时使用单列，避免跨列制造大空洞。允许附近位置回填，保留错落节奏；DOM 与查看器仍按收藏顺序，桌面键盘焦点可能有小幅向上移动。这些是可调整的设计选择，不是用户永久规格。追加不改变既有位置。
- `GalleryBrowse.astro` / `gallery.css`：浏览页面内容与样式，初始输出 24 项；容器单位让预计算坐标随宽度缩放，三个断点对应 2/4/6 个基础列。
- `browse.ts`：分段追加、视口附近加载/远处释放、视频播放状态、作品 URL 与返回；只在打开作品时加载查看器模块。
- `video-playback.ts`：区分用户播放意图与环境暂停，保留远处卸载前的进度；可独立验证异步媒体事件。
- `viewer.ts` / `GalleryLightbox.astro`：PhotoSwipe 交互与样式；依赖完整数据，独立于已挂载多少卡片。支持原图/原片、信息、复制作品链接和键盘操作。
- `GalleryExhibition.astro` / `exhibition.css`：展厅场景、昼夜光色、作品说明与方向控制。淡入在外层透视视口上合成，不对 `preserve-3d` 陈列层设置半透明，否则淡入结束时会从平面突然恢复透视。
- `src/lib/inertia-motion.ts`：首页与展览共享的连续运动核心。拖动速度采样、自由惯性、主动定位、恒速漫游与可选边界，不管理作品或 DOM。
- `exhibition-motion.ts`：展览专属的环形坐标、首尾取模与透视姿态。
- `exhibition.ts`：指针、方向键、Home/End、进度滑杆与运动模型的连接，以及就近作品陈列。只挂载附近九件作品，保持原始媒体与比例；退出模式释放媒体，离屏/隐藏暂停视频与动画。视频只在当前展位自动播放，可进入查看器使用原生控件。
- `modes.ts`：开屏选择与两种呈现之间的协调；展览脚本按需加载。`?mode=exhibition` 保留观看模式，作品仍使用 `#work=<id>`；共用一个查看器和历史状态。查看器切图同步展厅，返回浏览定位到当前作品。
- `src/pages/gallery/index.astro`：页面装配与两种模式容器。

展览和浏览共用 `GalleryEntry`、稳定作品 ID 与查看器；展览独立管理场景和资源，不读取瀑布流卡片布局。

## 添加内容

本地图片仍放在 `src/config/gallery.ts`；远端/公开目录图片仍在 `src/config/r2-gallery.json`。宽高必须是准确的正整数。图片 ID 来源于原始路径/URL 的哈希，重排不会改变 ID，换源会改变 ID。

视频放在 `src/config/gallery-videos.ts`，提供稳定 `id`、`src`、`poster`、`width`、`height` 和可选文字；海报不是视频的替代品。默认浏览在可见时静音循环播放，保留原生控制条和放大入口；离屏或打开查看器时暂停。用户手动暂停会被保留，远处卸载后尝试恢复播放进度。浏览器拒绝自动播放或用户要求减少动态效果时，原生控件仍可播放。当前真实收藏暂无视频，不能把类型检查等同于真实视频播放验收。

图片不重新编码，GIF 在浏览中使用动画原图。离开预加载范围后释放媒体源，再接近时恢复；GIF 可能从头开始。当前实现以分段 DOM 与离屏资源管理控制开销，没有宣称任意数量收藏的常量内存或稳定帧率。

## 验证

- `pnpm test:gallery`：包含共享运动测试；验证布局不变量（比例、边界、无重叠、追加稳定、有界回填）、媒体事件行为（手动意图、环境暂停、减少动态效果、自动播放拒绝、进度恢复），以及展览首尾循环、最近圈选择和透视坐标。测试不替代实际设备的手感审阅。
- `pnpm verify`：类型、相册行为测试、生产构建和发布产物；部署流程也运行相册测试。
- 浏览器：连续与反向滚动、原图/GIF、打开/切换/缩放/关闭、浏览器返回与直接访问作品链接、复制反馈、昼夜、窄屏和失败入口。

`docs/issues.md` 原文及旧技术文章描述的是历史问题/实现。需要判断当前行为时，以本文件、代码和本轮验证为准。

本轮用本地生成的 VP8 视频在浏览器验证了流内自动播放、原生暂停、查看器播放/切图暂停，以及离屏卸载后的暂停位置恢复；临时素材与页面已清理。这验证了播放机制，尚未覆盖真实收藏中的不同编码、远端视频和触摸设备。

展览本轮验证：`pnpm verify` 通过；生产预览中检查桌面昼夜、390px 窄屏、鼠标拖动、键盘选择、查看器切图/关闭、模式往返、浏览器历史前进/后退及返回浏览定位。触屏真机、减少动态效果的系统设置切换和真实远端视频尚未实测，不能由布局与媒体状态单测代替。两种模式现在都提供查看器加载失败反馈，展览还保留原文件入口。

共享运动与自动漫游调整后再次通过 `pnpm verify`。本地浏览器检查轻拖保留中间位置、开启/暂停、拖动接管、查看器停止漫游与首页作品跳转；实测漫游约 0.1 幅/秒，暂停与离屏约 33 秒期间的位置不变，并检查了 320px 与桌面控制栏。运动测试覆盖快速短甩、速度连续性、像素/展位坐标一致性、首尾边界及巡航。数学与浏览器结果不代表触屏真机和最终手感已由作者确认。
