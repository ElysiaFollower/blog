# 连续运动

`src/lib/inertia-motion.ts` 提供无 DOM 的 `InertiaMotion`，目前由首页收藏回廊与画廊展览共用。它只负责一维位置、速度、拖动采样、惯性衰减、指定位置的对齐和匀速巡航；作品索引、环形取模、透视构图、按钮与动画帧由各场景负责。

手动拖动保留任意中间位置。松手按最近 60ms 的速度自然减速，不自动吸附到作品；只有点击选择、方向键等明确定位操作调用 `select()`。再次按住或调用 `stop()` 都在当前可见位置停下。

惯性达到静止阈值时，在衰减曲线上结束积分，不一次补完理论上剩余的位移；否则最后一帧会在速度接近零时突然跳动。阈值跨越的那一帧只计算实际剩余运动时间，保留不同帧率下的一致性。

## 接入约定

- `new InertiaMotion({ position, scale, bounds })`：`scale` 是模型坐标中一幅作品的典型跨度，用于速度与静止阈值。展览以展位间隔计量，默认 `scale: 1`；首页以像素计量，使用 `scale: 420` 和首尾边界。
- `begin(x, time, pixelsPerUnit)`、`move(x, time)`、`end(x, time, cancelled, reducedMotion)`：输入坐标为指针像素，时间为毫秒；展览传入每个展位对应的拖动像素数，首页使用默认的 1:1 映射。松手事件也必须交给模型，以包含最后一段位移。取消和减少动态效果时直接停止。
- `select(position, immediate)`：主动对齐模型坐标。`target` 在对齐期间保留目的地，其余时间跟随当前位置，可用于连续按键选择。
- `startCruise(speed)`：速度单位为模型坐标/秒，短暂缓入后维持恒定速度；运行中再次调用保留当前位置与速度，平滑过渡到新速度。`stop()` 不会取整位置。
- `step(elapsed)`、`moving`：场景自行调度 RAF，模型用解析积分消除帧率对轨迹的影响。离屏、后台或查看器遮挡时暂停；恢复时重置帧时钟，不把隐藏期间的时间累计进去。

自动播放的启动、暂停与恢复策略不属于物理模型。展览默认开启自动漫游（减少动态效果时除外），默认 1× 约 10 秒经过一幅；滑杆支持 0.25×–3×，暂停时预选、播放中平滑变速，并在本地保存速度偏好。调整速度本身不会启动播放。漫游开关只由按钮控制。拖动时临时接管，松手后平滑恢复巡航；点击作品进入观察模式，先加速对齐再推进独立的 CSS 3D 镜头；观察期间不巡航，W/S 控制镜头距离、A/D 控制环形位置。镜头完全退回后才按开关状态恢复巡航。独立查看器或退出模式只暂时挂起，返回后保留开关状态。离屏和切后台只暂停，返回后继续。开启“减少动态效果”会停止当前运动；用户仍可通过漫游按钮主动选择持续旋转。

## 验证

首页与展厅的 DOM 输入均使用 Pointer Events。触摸会先隐式捕获到图片，拖动开始后转交舞台；
子元素的 `lostpointercapture` 会冒泡，不能当作舞台取消。仅在事件目标为舞台本身时结束该手势，
保持鼠标、触摸与笔共用同一套物理模型。依据 [Pointer Events 捕获转移约定](https://www.w3.org/TR/pointerevents/#process-pending-pointer-capture)。

`pnpm test:motion` 覆盖轻拖停在中间、快速短甩、末段位移、反向、抓停、边界、坐标单位缩放、输入/帧率一致性，以及巡航与暂停。`pnpm test:gallery` 包含这些测试，因此本地完整检查与现有部署检查都会执行。数学测试验证运动契约，实际设备的手感仍需浏览器审阅。
