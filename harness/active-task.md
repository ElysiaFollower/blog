# 当前任务：相册浏览升级

状态：本轮默认浏览重构已完成，可供作者审阅。展览模式仍属于后续独立任务。

本任务接替旧站点收口任务。来源：作者 2026-10-28、2026-10-29 的相册讨论；以这些明确意图为准，旧 Agent 的实现解释不能自动成为设计约束。

## 用户确认的目标与边界

- 用于欣赏、浏览和分享收藏，追求审美体验：好看、不卡、交互流畅。
- 同一份收藏提供浏览与展览两种观看方式。本轮先完成默认瀑布流浏览；展览的场景和美术方案后续独立设计。
- 美术可以大胆，结合现有页面优点与 `docs/art-inspiration/`；参考中的候选形式不是必须实现的要求。
- 素材在运行前可获得，宽高等元数据可预计算。懒加载、分批追加等是可调整的性能手段。
- 2026-10-30 补充：完整展示图片，不裁剪、保留比例、支持不同尺寸；允许适度缩放、间距变化与不过分的留白。不以填满版面为目标牺牲图片。
- 代码需有清楚边界，便于维护；不为了未来展览预造插件框架。
- 不部署、不更改其他页面。现有收藏为图片（含 GIF）；支持视频接入时需区分播放机制验证与真实收藏验证。
- 用户授权在 `dev-gallery` 分支阶段性提交；不 push 到远端。

## 当前实施方案（Agent 选择，可据验证调整）

- 统一稳定作品 ID 与预先准备的尺寸；保留原图质量与 GIF 动画。用户进一步明确：不以降低视觉效果换性能，重点优化懒加载、分段展示与离屏资源。
- 独立浏览组件负责连续追加、横竖幅比例、链接与返回状态；纯布局函数可独立测试。
- 单图查看继续使用 PhotoSwipe，按需加载，恢复常用手势，并独立于瀑布流 DOM。
- 保留中文画册气质、昼夜环境与图片主体地位；本轮不放不可用的展览开关。

## 验收

- `pnpm test:gallery` 验证不重叠、比例、边界、追加稳定、回填范围和视频播放意图。
- 数据检查确认所有现有作品保留、浏览直接使用原图，GIF 在浏览中可播放。
- `pnpm verify` 通过类型、生产构建与发布产物检查。
- 真实浏览器检查桌面/窄屏、昼夜、滚动增量、灯箱、键盘、深链/返回；明确区分已验证与未测的触控/性能场景。
- 记录构建产物和运行观察；没有测量证据不宣称稳定帧率或任意规模性能。
