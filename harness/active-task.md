# Active Task

## 目标

将已经选定的混合型方向继续发展为完整、自洽、可在本地真实使用的 Astro 博客主题演示站。展示页保留明确的导演感，文章和内容检索页保持安静、高效，直到整体完成度足以进行系统性的视觉与交互评审。

## 当前事实与决定

- 该仓库是强主见的 Astro Starter Theme 及其演示站，不是临时产物。
- 主题首先服务于 ElysiaFollower 的个人博客，开源复用不反向约束设计。
- 展示页可以具有强烈美术表达和丰富交互；文章等功能页必须安静、清晰、快速。
- 旧博客素材可在当前私有开发阶段直接作为 Demo 使用。
- Astro 负责静态页面、内容模型和按需交互；不从现成主题继续修改。
- 正式博客未来从稳定主题版本一次性派生，不要求持续同步主题上游。
- 混合型是正式首页方向；另外两种概念只保留为设计过程参考。
- 首页不承担个人履历展示；独立的 About 页面负责组织个人身份、研究方向、兴趣与联系方式。
- 当前优先保证桌面端整体设计，窄屏先满足可用、可读和无溢出。

## 非目标

- 当前不创建公开远端或部署生产站点。
- 当前不迁移全部历史文章。
- 当前不处理 Demo 素材的公开授权。
- 当前不建设通用插件系统、主题市场兼容层或长期升级协议。
- 当前不实现 Muse 服务端集成。

## 实施方案

1. 将混合型提升为正式首页，评审路由复用同一个实现，避免形成两份首页代码。
2. 建立独立的个人资料配置与 About 页面，用章节化构图承载个人叙事。
3. 继续补齐分类、标签、归档等内容检索路径，并统一现有文章、相册和友链页面的完成度。
4. 收敛昼夜主题、导航、音乐、动效与页面之间的视觉语言。
5. 通过构建、类型检查和真实浏览器截图持续验证桌面端、窄屏和渐进增强。

## 验收标准

- `pnpm build` 成功生成静态站点。
- `/` 使用正式混合型首页且不出现评审控件；概念页面仍可通过独立 URL 回看。
- About 页面能独立、清楚地表达个人研究主线、兴趣与联系入口。
- 文章页在桌面端具有稳定正文行宽和可用侧栏空间，在移动端不产生横向溢出。
- 展示页包含可体验的导演性细节，但导航无需说明即可识别。
- 关键页面在 JavaScript 失败时仍能访问主要内容与链接。
- 支持 `prefers-reduced-motion`，触摸设备不依赖自定义指针完成操作。
- Playwright 桌面和移动截图不存在文字、导航、图片或控件的无意义重叠。

## 协作方式

低风险实现与局部设计决策由 agent 自主推进。涉及产品目标、仓库公开、生产部署、远端覆盖或明显改变主题方向的决定再请求用户确认。
