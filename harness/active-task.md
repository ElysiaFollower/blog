# Active Task

## 目标

把已经定型的 Astro 博客主题收口为可以正式部署的个人站：展示页保留明确的导演
感，文章阅读与知识检索保持安静、高效；源码、历史内容、旧链接、搜索、SEO 与
GitHub Pages 部署形成一套完整工作流。

## 当前事实与决定

- 仓库是强主见的 Astro 博客主题及其演示站，不是临时产物。
- 主题首先服务于 ElysiaFollower 的个人博客，开源复用不反向约束设计。
- 首页、About、友链与相册负责个人表达；文章浏览、知识目录与阅读页优先保证
  清晰和速度。
- 文件系统同时承担本地知识目录、网站目录和文章 URL；Tags 只表示交叉关系。
- 所有文章统一使用 MDX。普通文章直接写 Markdown，需要时再插入集中注册的
  旁注、媒体、舞台或交互组件。
- 历史文章已经迁入新内容模型；旧 Hexo URL 由静态重定向页兼容。
- GitHub Pages 使用 GitHub Actions 构建 `dist/`，不再提交构建产物。
- 当前优先保证桌面端整体设计，窄屏同样必须可用、可读且无页面级溢出。

## 非目标

- 不为了主题市场或通用性削弱当前构图、字体关系和交互节奏。
- 不建设服务端内容系统、数据库或 Muse 集成。
- 不在没有用户确认时创建远端、覆盖发布仓库或执行生产部署。
- 不把“代码可部署”等同于 Demo 图片和音乐已经获得公开再分发许可。

## 验收标准

- `pnpm check` 与 `pnpm build` 成功，Pagefind 能索引全部公开文章。
- 全站主要路由、内部链接、旧链接、RSS、站点地图与 SEO 元数据正确。
- 文章目录、Tags、全文搜索、排序、代码复制、脚注与交互组件真实可用。
- 相册按需加载图片，灯箱支持缩放、拖拽、切图与键盘关闭，加载时不发生明显
  布局偏移。
- 桌面端与窄屏没有页面级横向溢出、文字遮挡或无法操作的控件。
- 支持 `prefers-reduced-motion`；触摸设备不依赖自定义指针完成操作。
- GitHub Actions 在部署前执行依赖安装、内容检查、生产构建和产物验证。

## 协作方式

低风险实现、验证与局部设计决策由 agent 自主推进。仓库公开、素材授权、远端
创建、生产部署和会改变主题方向的决定由用户确认。
