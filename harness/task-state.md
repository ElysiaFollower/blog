## 当前工作点

首轮评审已选择混合型作为正式首页骨架。根据反馈完成了开屏节奏和桌面文章密度的第一轮调整，等待用户复看文章页。

## 关键工作记忆

- 混合型负责最终首页结构；氛围型只保留昼夜美术、书法标题和引语等语言参考；图形型停止发展。
- 文章页被有意设计为独立的安静阅读系统，不需要跟随最终首页的视觉强度。
- 当前优先桌面端整体协调性；移动端只维持正确布局、可访问性和无溢出等基础保障。
- 开屏、自定义指针、主题切换和音乐都是渐进增强；无 JavaScript 时主要内容、系统光标、导航和相册原图链接仍可用。

## 最近验证

- `pnpm check && pnpm build && git diff --check`：24 个 Astro 文件无诊断，12 个静态页面和 66 个响应式图片变体构建成功。
- `astro preview` + Playwright：8 个代表性生产路由均返回 200；桌面 1440px 与手机 390px 无横向溢出、无控制台错误、无可见破图。
- Playwright 交互：昼夜切换、相册打开与资源清理、首次开屏 session、无 JavaScript 降级和 `prefers-reduced-motion` 均通过。
- 调整后 Playwright：首次进入开屏约 1.3 秒后完整离场；同一会话刷新在首帧即带有 `opening-seen`，不再闪烁；桌面正文宽 780px、行高约 32.6px，目录与侧注无重叠。
