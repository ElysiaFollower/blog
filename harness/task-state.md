# 任务状态快照

- 对应任务：`harness/active-task.md`
- 更新时间：2026-07-30

## 当前工作点

混合型正式首页、About 与友链的展示语言已完成一轮统一。首页现在以静止首屏、文章、频道索引和图像收藏形成四幕节奏；友链在仅有一个真实样本时也拥有成立的独立构图。内容发现体系已贯通最新文章、年份归档、分类、标签、搜索和阅读页。

## 关键工作记忆

- 混合型负责最终首页结构；氛围型只保留昼夜美术、书法标题和引语等语言参考；图形型停止发展。
- 文章页被有意设计为独立的安静阅读系统，不需要跟随最终首页的视觉强度。
- 当前优先桌面端整体协调性；移动端只维持正确布局、可访问性和无溢出等基础保障。
- 开屏、自定义指针、主题切换和音乐都是渐进增强；无 JavaScript 时主要内容、系统光标、导航和相册原图链接仍可用。
- 首页负责第一印象与内容入口，不插入个人履历；About 页面负责身份、研究、兴趣与联系信息。
- 首页背景保持静止，复杂度来自内容分幕而不是持续缩放；站内文章、相册与 About 通过频道索引明确分工。
- 展示页的滚动揭示由 `ScrollReveal.astro` 统一提供；无 JavaScript 或系统要求减少动态效果时，内容直接可见。
- 个人资料集中在 `src/config/profile.ts`，页面构图仍由主题直接决定。
- 文章关系集中由 `src/lib/posts.ts` 从 Astro 内容集合派生；新增内容无需维护手写索引。
- `/posts/`、`/archives/`、`/categories/` 和 `/tags/` 是同一内容集合的四种视图，主导航统一将它们归入“文章”。
- 友链只保存外部朋友站点；个人 GitHub、Academic 与邮箱入口归 About 管理。

## 最近验证

- `pnpm check`：43 个 Astro 文件无诊断；`pnpm build`：35 个静态页面与 RSS 构建成功。
- Playwright 桌面 1440px、窄屏 390px 和最小 320px：文章、归档、分类、标签、相册、友链、阅读页与 404 均无横向溢出或控件重叠。
- 本轮 Playwright 复核首页、About 与友链：桌面 1440px 和窄屏 390px 无横向溢出，首页 8 个、About 14 个、友链 3 个揭示节点全部按滚动触发。
- 首页首屏背景计算样式无动画；禁用 JavaScript 时揭示内容保持可见；`prefers-reduced-motion` 下位移与透明度动画被关闭；三个页面无运行时错误。
- 40 个代表性内部链接全部返回 200；缺失路由返回自定义 404。
- 搜索过滤与清空、taxonomy 跳转、动态阅读时长、相邻文章、相册前后切换与键盘操作、代码复制反馈均通过。
- 禁用 JavaScript 时搜索控件隐藏但五篇文章完整显示，相册链接仍打开原图，代码块保持原始可读状态。
- RSS 通过 XML 校验；canonical 与 Open Graph 链接指向生产域名；概念评审页已从 sitemap 排除。
